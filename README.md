# Student Performance Dashboard in Excel

## Project Overview
Interactive Student Performance Dashboard created using Microsoft Excel.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards

## KPI
- Total Students
- Average Marks
- Highest Marks
- Pass Percentage

## Dashboard Features
- Average Marks by Subject
- Average Marks by Class
- Count of Students by City
- Gender-wise Average Marks
- Interactive Slicers
